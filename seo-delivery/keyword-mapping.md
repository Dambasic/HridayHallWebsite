## 3. Implementation Guidelines for Content Updates

1. **Title Tag Rule**: Always front-load the primary keyword, keep under 60 characters, and end with `| Hriday Banquet Hall`.
2. **Meta Description Rule**: Include primary + 1 secondary keyword, maintain an active voice, embed an explicit Call-To-Action ("Request a quote on WhatsApp"), and cap at 155 characters.
3. **Heading Rule**: Exactly one `<h1>` per page matching search intent, followed by logical `<h2>` and `<h3>` tags.
4. **Natural Integration**: Never stuff keywords consecutively; write for human event organizers and couples first.
